# Icons

The `prime-icons` crate contains 53 PrimeNG SVG icons (`packages/primeng/src/icons`, without `baseicon`) plus `BlankIcon`.
Each icon is enabled by its own feature flag (the PrimeNG directory name: `check`, `chevrondown`, …); `all-icons` enables all of them.

```toml
prime-icons = { path = "crates/prime-icons", features = ["check", "chevrondown"] }
```

```rust
view! { <CheckIcon /> }                         // decorative: aria-hidden="true"
view! { <CheckIcon aria_label="Done" /> }       // role="img" + aria-label
view! { <SpinnerIcon spin=true size=20u32 class="custom" /> }
```

The code is generated by `cargo xtask gen-icons` from the PrimeNG sources (the path is in `upstream.toml`). Generation is deterministic:
a repeated run does not change the files. The `tests/upstream.rs` test compares the `d` and `viewBox` of every icon with the source.

Difference from PrimeNG: the `<g clip-path>` wrapper + `clipPath` over the whole `viewBox` is not reproduced, because it clips nothing.

## Contribution to wasm size

Raw `.wasm` (release, without `wasm-opt`, `cargo build -p wasm-size --release --target wasm32-unknown-unknown --features case-…`):

| Case | Size, bytes | Difference from baseline |
|---|---|---|
| `case-baseline` (empty `div`) | 1 235 486 | — |
| `case-one-icon` (`CheckIcon`) | 1 243 662 | +8 176 |
| `case-all-icons` (54 icons) | 1 362 853 | +127 367 (≈ 2.4 KB per icon) |

Icons that are not enabled do not end up in the binary: `case-one-icon` differs from `case-all-icons` by ≈ 119 KB.
