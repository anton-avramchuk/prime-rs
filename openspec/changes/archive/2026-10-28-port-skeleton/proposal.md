# Proposal

## Why

Skeleton is a loading placeholder; the first component of wave 2. It is purely presentational (without behaviour), so it serves as a check of the template on a component whose markup is entirely defined by the style (`width`, `height`, `border-radius`), and it opens wave 2 together with Textarea.

## What Changes

- A new crate `prime-skeleton` with the `Skeleton` component: `shape` (`rectangle` by default, `circle`), `animation` (`wave` by default, `none`), `border_radius`, `size`, `width` (default `100%`), `height` (default `1rem`), `style_class`, `pt` (`root`).
- Markup and classes as in PrimeNG 21.1.10: `<div class="p-skeleton p-component" aria-hidden="true">` with the modifiers `p-skeleton-circle`, `p-skeleton-animation-none`, `data-p` (the shape) and the inline style `position: relative; width: …; height: …; border-radius: …` (with `size` the width and height equal `size`).
- The `/skeleton` page (`shapes`, `card`, `list`), e2e, benchmarks, budgets. The CSS of the themes `skeleton` and `textarea` is generated by `cargo xtask gen-theme` (the component list is in `upstream.toml`).
- **Not included:** the `datatable` demo (it needs a table); the Tailwind utilities of the demos are replaced by inline styles.

## Impact
