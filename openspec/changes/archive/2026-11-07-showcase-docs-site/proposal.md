# Proposal

## Why

Сейчас showcase — набор страниц с живыми демо без пояснений, а документация лежит отдельно в `docs/*.md`. Нужен результат, который можно показать и по которому можно учиться: сайт «демо + документация» в духе primeng.dev/components (страница компонента: заголовок и описание, импорт, примеры с живым результатом и кодом, справочник API, оформление, доступность).

## What Changes

- Страница компонента получает единую оболочку `DocPage`: заголовок, краткое описание, блок «Import», примеры (живое демо + кнопка «Code» с кодом на Rust), разделы API (Props, Events, Pass Through, Theming/CSS-классы), «Accessibility», боковое оглавление страницы («On this page») и переход к соседним компонентам.
- Левое меню группируется по разделам, как в PrimeNG (Form, Button, Data, Panel, Overlay, File, Menu, Messages, Media, Misc), поиск по имени.
- Код примеров не пишется вручную: `cargo xtask gen-docs` вытаскивает исходник каждого демо из `showcase/src/pages/*.rs` (компонент `#[component] fn …`, на который ссылается `<Demo>`), чтобы код всегда совпадал с живым результатом.
- Справочник свойств, событий и частей Pass Through строится из исходников крейтов (`#[component]` с `///`-документацией и типом свойства), без ручной таблицы.
- Тексты `docs/<имя>.md` (совпадает, отличия, не вошло, не проверялось) показываются на странице раздела «Notes» (рендер Markdown на этапе генерации).
- Результат — сгенерированные файлы `showcase/src/generated/*` (в репозитории) и проверка актуальности `cargo xtask gen-docs --check`.
- Публикации нет: запуск локально (`cargo leptos serve` в `showcase/`).
- **Не входит:** деплой (GitHub Pages), поиск по содержимому, версии документации, страницы руководств (Installation, Theming) — после согласования.

## Capabilities

### New Capabilities
- `docs-site`: оболочка страницы компонента, генерация кода примеров, справочника API и заметок из исходников.

### Modified Capabilities
<!-- Нет. -->

## Impact

- `xtask` (новая команда `gen-docs`, зависимость `pulldown-cmark`), `showcase/src` (`doc.rs`, `generated/`, `app.rs`, `pages/mod.rs`: `Demo` получает связь с кодом), `showcase/Cargo.toml`, e2e (`docs.spec.ts`), `ci.yml` (проверка `gen-docs --check`), `docs/`.
- Страницы компонентов остаются, меняется только оболочка вокруг демо; разметка `[data-demo]` и идентификаторы сохраняются, чтобы не ломать e2e.
